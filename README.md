# Varun Singh Parmar · Portfolio v3

A visually refreshed, editorial, unobstructed-portrait, responsive **single-page HTML/CSS/JavaScript portfolio** designed for recruiters. No build system or paid services required.

## Version 3 homepage update
The first screen has been redesigned with uncluttered editorial typography and a standalone portrait. No floating badges, stickers or tags appear on or over the image. The remaining portfolio content and interactions are retained.

## Preview locally
Open `index.html` in a browser, or run `python -m http.server 8000` inside this folder and open http://localhost:8000/.

## Publish for free with GitHub Pages

1. Create a **public** repository on GitHub (e.g. `varun-portfolio`).
2. Upload `index.html`, `styles.css`, `main.js`, and the entire `assets/` folder to the repository root (do not upload only the ZIP).
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. Use the live site URL displayed in GitHub Pages Settings. It may take a few minutes for GitHub to publish.

You can also use Cloudflare Pages or Netlify by dragging the unzipped folder to their upload flow. This website has no dynamic backend, login or data collection.

## Site organization
- `index.html`: factual portfolio copy and layout
- `styles.css`: responsive design, motion and accessible design
- `main.js`: gallery filters, lightbox, menu, scroll reveal, reading progress
- `assets/`: uploaded media, optimized photos and downloadable résumé PDF
